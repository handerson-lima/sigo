- (direction) User wants to replace 'Obras' with 'Loteamentos' when clicking on a 'construtora' card.
- (decision) The new hierarchy must be exactly: LOTEAMENTO -> QUADRA -> LOTE -> ETAPA -> EQUIPE.
- (constraint) Term 'Obras' and 'Setor' are abolished in favor of 'Loteamentos' and 'Etapa' respectively.
- (capability) Users can navigate deeply into the hierarchy from Loteamento down to Equipe, seeing the relevant cards at each level.
- (event) Self-Validate Pass 1 (Coherence) & Pass 2 (Preservation): Validated. All constraints and capabilities captured into SPEC.md.
- (decision) No migration script is needed for Firestore data. Data in the development environment can be deleted and we will start from scratch.
- (decision) Lotes contain multiple specific Etapas (e.g. Muro, Cinza/1ª, Cinza/2ª, Cinza/3ª, Branca/Acabamento) rather than a single Etapa layer, and each of these Etapas has its own Equipe.
- (event) Self-Validate Pass 1 & 2: Validated updated spec with hierarquia-etapas companion.
- (decision) Stories breakdown generated into stories.yaml with 4 execution steps.
