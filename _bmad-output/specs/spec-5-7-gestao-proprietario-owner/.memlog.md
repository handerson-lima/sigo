# Memlog — SPEC-5-7-gestao-proprietario-owner
topic: Atribuição e Gestão de Proprietário (Owner) no SIGO

- [decision] Criar especificação formal para permitir atribuição e visualização do papel 'owner' (Proprietário) no SIGO.
- [constraint] Apenas desenvolvedores globais ativos (dev_roles/{uid} com isActive: true) têm permissão para atribuir ou destituir um proprietário (isOwner: true).
- [constraint] Administradores delegados comuns (isAdmin: true) não podem se autopromover a owner nem remover/alterar um proprietário existente.
- [capability] CAP-1: Backend Cloud Function (setMembership/setConstrutoraRole) passa a aceitar role: 'owner' e atribui isOwner: true quando invocado por dev.
- [capability] CAP-2: Invariante de proteção contra usurpação e destituição por administradores não-devs (permission-denied).
- [capability] CAP-3: Criação de construtora no painel dev com possibilidade de vincular o proprietário inicial.
- [capability] CAP-4: Mapeamento de isOwner no modelo Membro e exibição visual explícita com badge/ícone distintivo na MembrosScreen.
- [capability] CAP-5: Exposição da opção 'Proprietário' (owner) no dropdown de papéis no UserDetailsScreen e AddMembroDialog para devs.
- [capability] CAP-6: Cobertura automatizada de testes para autorização e UI do papel de proprietário.
