- (constraint) Parent AD-1: Modelo Relacional Flat no Firestore. As coleções (loteamentos, quadras, lotes) devem residir na raiz do Firestore.
- (constraint) Parent AD-2: Rotas Declarativas Aninhadas Refletindo Hierarquia.
- (decision) Parser Boundary and Stack: The DXF parsing and heavy geometry computation (Point-in-Polygon) will happen in a Python Cloud Function using ezdxf and shapely, returning a GeoJSON. Binds: Data Import Pipeline. Prevents: Thread-blocking heavy geometry math in Flutter Web and reliance on immature Dart CAD libraries.
- (decision) State Mutation and Async Flow: DXF uploads go directly to Cloud Storage, triggering a background Python Cloud Function. The function writes the GeoJSON result to a top-level 'loteamentos_drafts' collection in Firestore. Binds: Import Flow, UI State. Prevents: HTTP timeouts on large files and lost progress on UI unmount.
- (decision) Ambiguity Resolution and Ingestion: Backend applies heuristics to solve multiple texts per polygon. Unresolved lots get 'status: ambiguous' in GeoJSON for UI manual fix. Final ingestion to AD-1 Flat structure is done by a backend Cloud Function, not the UI, to safely handle Firestore 500-write batch limits. Binds: Data Import Pipeline, UI State. Prevents: Client-side transaction failures and UI freezing during massive batch writes.
